# Portfolio Website

Portfolio personal desarrollado con Next.js, React, Tailwind CSS, Framer Motion e i18n para mostrar perfil profesional, proyectos y formulario de contacto.

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```

## Desarrollo local

1. Instalar dependencias con `npm install`
2. Crear o completar `/.env.local` con las variables necesarias
3. Ejecutar `npm run dev`
4. Abrir `http://localhost:3000`

## Variables de entorno

El formulario de contacto usa estas variables:

```env
RESEND_API_KEY=tu_api_key
FROM_EMAIL=tu_correo_verificado
```

## Stack

- Next.js
- React
- Tailwind CSS
- Framer Motion
- i18next
- Resend
